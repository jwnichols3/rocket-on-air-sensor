What this page can and cannot change

Local edits are presentation only — label, text colour, background — and apply to this panel alone. Whether a row is busy, and which rows exist at all, is always the server's. The panel keeps pulling the profile, so a row the server adds later arrives with the server's own look and needs nothing done to it.

Background brightness picks the calm SHAPE on this 128×64 1-bit glass. Luminance is the firmware's own integer Rec.601 value, (299×R + 587×G + 114×B) / 1000, truncated: 128 or over draws the heavy double frame, under it the open ring. The meter on each card is that exact number. Colour never reaches a busy row — a busy row is a solid block with the label knocked out whatever its colours are, because a dark red and a dark green have near-identical luminance and a false OFF is the one error that matters.

This page edits at most the first 24 rows of the profile. If the profile is longer, a banner here names the total and says the rest still render on the panel and must be edited in the admin console.
